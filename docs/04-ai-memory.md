# AI & Memory Architecture

Kontextschichten: aktueller User-Kontext, aktive Marke, aktuelles Objekt, relevante Memories/Wissen, relevante jüngere Interaktionen. Nicht die ganze Datenbank senden.

Memory States: observed, learned, core, rejected. Ein einzelner Kommentar wird nicht sofort Kernregel.

Signale: manuelle Änderungen, Ablehnung, akzeptierte Vorschläge, explizites Feedback, wiederholte Präferenzen. Wiederholtes Aufschieben nur schwach werten.

Explainability: Confidence, Evidenz, Anzahl Signale, erste Beobachtung, letzte Verstärkung, Scope/Brand.

Entscheidungen separat speichern.
