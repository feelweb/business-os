# Design System

Einzige Farbwelt: Weiß, Schwarz, RemindFuel Gradient.

Light: Weiß als Basis, Schwarz für Text/UI, neutrale Abstufungen über Schwarz-Opacity.
Dark: Schwarz als Basis, Weiß für Text/UI, neutrale Abstufungen über Weiß-Opacity.

Gradient als zentrale Tokens: start, mid, end, main, glow. Finale Hexwerte nicht erfinden.

Keine Statusfarben. Zustände über Icon, Gewicht, Typografie, Border, Muster, Opacity und Position darstellen.

Typo: DM Sans Bold für Display, Garet für Body/UI, keine Serifenschrift.

UI: wenig klassische Karten, große Flächen, großzügige Abstände, asymmetrische aber intuitive Layouts, subtile Gradient-Lichtflächen, reduzierte Navigation, progressive disclosure, ruhige Microinteractions.
